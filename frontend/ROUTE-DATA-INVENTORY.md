## Shared transport and auth

- `@ksu/api-client/server` is the server-only entry for request-scoped backend access; `@ksu/api-client/browser` owns browser credentials, refresh coordination and cancellation.
- Public server GETs carry the shared `ksu-public-content` tag. Web, Library, Research and HERI expose authenticated `/api/revalidate` handlers; Admin calls the owning app after confirmed mutations and client query invalidation.
- Server loaders return serializable DTOs only. No transport, `Response`, token, internal origin or mutable session object crosses a client boundary.
- Admin is the explicit static-export exception: authenticated/live data remains browser-owned because no request-time frontend server exists in that deployment.
- Interactive streams, uploads, media-body proxying and filter refreshes are deliberate browser exceptions documented by their owning route.
