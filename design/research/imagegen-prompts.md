# Imagegen Prompt Log

These assets were generated with the built-in imagegen workflow as high-fidelity UI mockups. They are design references, not direct screenshots from the app.

## Shared Prompt Direction

- Use case: `ui-mockup`
- Product: KSU Research public frontend
- Style: institutional, public university, clean typography, full-width bands, restrained green/gold/charcoal palette
- Layout: preserve the main public site's width coverage, three-column rhythm, practical navigation, and image-led sections
- Data posture: backend-backed content only; no dummy lorem ipsum
- Avoid: decorative blobs, abstract gradients, nested cards, dark blurred heroes, one-note palettes, marketing-only splash sections

## Reuse Rules

- Use one image per implementation pattern, not one image per database model when two models share the same public experience.
- Program, center, farm, sustainability, and partner pages should use relationship panels that show connected projects, outputs, events, funders, and people in public-friendly language.
- Detail pages should explain relationships as "Part of", "Supported by", "Led by", "Related outputs", "Community reach", or "How to participate"; avoid backend terms such as foreign keys or join tables.
