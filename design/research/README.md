## Guideline Documents

- [Page guidelines](page-guidelines.md) maps each public research page to layout, data, filters, relationships, and actions.
- [Imagegen prompt log](imagegen-prompts.md) records the prompt strategy used for the design references.

## Implementation Intent

- Borrow architecture and data relationships from the older research frontend.
- Keep the current public site's established styling, typography, layout density, and institutional tone.
- Keep all page content backend-backed. Empty states are acceptable; dummy content is not.
- Use full-width bands and the public site's column rhythm. The landing page can use a full-width hero; inner research pages should not use hero sections.
- Use imagery deliberately on landing, farm, sustainability, community, innovation, and selected listing cards.
